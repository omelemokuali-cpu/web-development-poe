## Project Description
KOENA HOUSES is a responsive real estate website for buying luxury houses in South Africa. The site allows users to view properties, enquire about houses, and contact the agency.

## Features
- Responsive design (mobile & desktop)
- Property listings with prices (e.g. R2,450,000)
- Navigation: Home, About, Properties, Services, Contact, Enquiry
- Contact form and enquiry form
- Image gallery

## Pages
1. index.html - Home page
2. about.html - About KOENA HOUSES
3. properties.html - All property listings
4. service.html - Our services
5. contact.html - Contact form
6. enquiry.html - House enquiry form
7. style.css - All styling
8. images/ - All house images
